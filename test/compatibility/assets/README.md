# Fixtures de compatibilidade autorizadas

Estas três saídas sintéticas da biblioteca local insinfo_dart_pdf foram
copiadas por autorização expressa do usuário. Origem, scripts geradores
identificados e SHA-256 constam de manifest.json. Não foi encontrada licença
separada na origem; este registro não atribui MIT aos arquivos.

Os PDFs de assinatura são cenários artificiais produzidos por geradores
locais. Nenhum PFX, chave privada ou documento pessoal foi copiado.
O documento de três páginas contém somente Contract page 1/2/3; não foi
localizado seu gerador. Os testes verificam abertura, páginas e extração.
Validade criptográfica, conformidade de política/timestamp e aplicação de
permissões DocMDP não são certificadas por esses testes.
